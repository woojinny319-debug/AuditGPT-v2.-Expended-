# AuditGPT

K-IFRS 기준서 · DART 공시 · 회계법인 KAM/가이드북을 근거로 답변하는 다산업 회계감사 RAG 챗봇입니다.

## 목적

감사인이 여러 산업의 회계기준·공시 사례·실무 가이드를 하나의 창구에서 빠르게 교차 확인할 수 있도록 돕는 것을 목적으로 합니다. 답변마다 근거 문서를 명시적으로 인용해, 실제 감사 업무에서 신뢰하고 검증할 수 있는 형태의 자료로 활용하는 데 초점을 둡니다.

## 무엇을 하는가

- **K-IFRS 11개 기준서**(수익, 리스, 금융상품, 유형자산, 무형자산 등) 기반 회계 원칙 질의응답
- **DART 공시 데이터**: 5개 산업(제약·바이오, 건설, 에너지·유틸리티, 외식, 소비재·유통) 총 79개 상장사의 최근 사업보고서
- **삼일회계법인 산업별 가이드북/KAM** 문서 기반 실무 사례
- 질문에 언급된 기업·산업을 자동 감지해 관련 문서만 우선 검색하고, 답변마다 근거 문서를 `[S#]` 형태로 인용

## 기존 AuditGPT에서 개선된 점

| 구분 | 기존 | 개선 |
|---|---|---|
| 산업 범위 | 제약·바이오 1개 산업 전용 | 5개 산업(제약·바이오/건설/에너지·유틸리티/외식/소비재유통), DART 79개사로 확장 |
| 할루시네이션 | 근거가 약해도 그대로 인용 근거로 채택 | FlashRank 관련도 임계값 활성화, 기업명 없는 일반 질문엔 DART를 배제하고 기준서·가이드북 우선 |
| 산업 교차오염 | 무관한 산업의 사례가 섞여 인용될 수 있음 | 질의된 산업과 무관한 사례가 섞이지 않도록 검색 단계에서 필터링 |
| 출처 투명성 | 본문에 직접 인용된 출처만 표시 | 기준서/가이드북·KAM/DART 카테고리별로, 인라인 인용이 없어도 실제 검색에 쓰인 출처를 항상 표시 |
| 서비스 형태 | Streamlit 단일 프로세스(로컬 실행 전용) | FastAPI + 정적 프론트엔드로 분리해 독립적인 웹 서비스로 배포 가능 |
| 사용성 | 최소한의 UI | 로딩 애니메이션, 예시 질문 제공, 비교 질문 시 표 자동 정리, 답변 내 기업명 자동 강조 |

## 기대효과

- 감사인이 여러 산업의 회계 이슈를 하나의 도구로 신속하게 조회
- 답변 근거의 투명한 인용으로 검증 가능성과 신뢰도 향상
- 산업별로 무관한 사례가 섞이지 않아 실무 적용 시 오판 위험 감소
- 독립 웹 서비스 형태로 배포해 다른 팀원과 손쉽게 링크 공유 및 협업 가능

## 기술 스택

| 구성요소 | 기술 | 기능 |
|---|---|---|
| RAG 오케스트레이션 | LangChain | 리트리버·문서·임베딩/LLM 클라이언트를 표준 인터페이스로 묶어 검색 파이프라인을 구성 |
| 벡터 DB | ChromaDB | 문서 임베딩을 저장하고 질의와의 유사도로 관련 문서를 검색(시맨틱 검색 축) |
| 키워드 검색 | rank-bm25 | 단어 빈도 기반 검색으로 정확한 숫자·고유명사 매칭을 보완(BM25 검색 축) |
| 재순위화 | FlashRank | Cross-Encoder로 1차 검색 결과를 재정렬·필터링해 정밀도를 높이는 2단계 리랭커 |
| 임베딩·LLM | OpenAI (`gpt-4o`, `text-embedding-3-small`) | 텍스트 임베딩 생성과 최종 답변 문장 생성 |
| PDF 파싱 | PyMuPDF | K-IFRS·KAM·가이드북 PDF에서 텍스트 추출 |
| DART 수집 | requests, BeautifulSoup4 | DART 공시 원문 크롤링 및 표 파싱 |
| 백엔드 | FastAPI | 검색·답변 생성 로직을 HTTP API(`/api/chat`, `/api/health`)로 노출 |
| ASGI 서버 | Uvicorn | FastAPI 앱을 실제로 구동하는 실행 엔진 |
| 프론트엔드 | 정적 HTML/CSS/JS | 빌드 도구 없이 채팅 UI를 구성, marked.js로 마크다운 답변을 렌더링 |

## 프로젝트 구조

```
industries.py       # 산업별 대상 기업·가이드북·DART 수집 설정 (단일 진실 공급원)
rag_engine.py        # 리트리버(하이브리드 검색 + FlashRank) 구성
prompts.py            # 시스템 프롬프트, 인용 포맷
dart_ingest.py        # DART 공시 수집 스크립트
backend/main.py       # FastAPI 앱 (/api/chat, /api/health)
frontend/              # 정적 웹 UI
deploy/                 # systemd/nginx 배포 설정 예시
```

## 실행 방법

```bash
pip install -r requirements.txt
```

`.env` 파일에 API 키 설정:

```
OPENAI_API_KEY=...
DART_API_KEY=...
```

DART 데이터 수집(최초 1회, 산업별로 나눠서 실행 가능):

```bash
python dart_ingest.py --industry bio
```

서버 실행:

```bash
uvicorn backend.main:app --host 127.0.0.1 --port 8000
```

브라우저에서 `http://127.0.0.1:8000` 접속.
